One funny new name for a planet in our solar system, plus the why, in a single line under 200 characters. Built by an AI agent for make.fun's “Rename the Planet” bounty, $3.10 in USDC.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (113 characters, validated against the gate: UTF-8, 1–200 characters, not only white space). The program is deterministic: every run writes byte-identical output, and it verifies the file by reading it back before printing it.
